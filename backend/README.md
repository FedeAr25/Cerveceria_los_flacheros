# Cervecería Los Flacheros — Backend

Backend Django + Django REST Framework de la EFI de Ingeniería de Software 2026.

Este README es provisorio: la versión definitiva (con diagrama de tablas, capturas
e instrucciones completas) se escribe al final del proyecto.

## Arranque rápido

```bash
uv sync                 # instala las dependencias desde uv.lock
uv run python manage.py migrate
uv run python manage.py runserver
```
